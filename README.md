# 📱 الحساب اليومي — تطبيق أندرويد

تحويل موقع [volt-ledger-six.vercel.app](https://volt-ledger-six.vercel.app/) (نظام محاسبي شخصي لفني الكهرباء) إلى تطبيق أندرويد حقيقي، مبني بـ **Capacitor** — بحيث يعمل **بدون إنترنت** لأن كل البيانات تُحفظ محليًا على الجهاز (IndexedDB).

![icon](public/icon-192.png)

## ✨ المميزات

- ✅ تطبيق أندرويد حقيقي (APK) بملف قابل للتثبيت مباشرة
- ✅ يعمل **بدون إنترنت** — بياناتك كلها على جهازك
- ✅ الواجهة نفسها: تقارير، رسوم بيانية، تصدير PDF، نسخ احتياطي
- ✅ مشاركة/حفظ ملفات التصدير (PDF / نسخة احتياطية) عبر نافذة المشاركة في أندرويد
- ✅ أيقونة وألوان مطابقة للموقع (أزرق + صاعقة ⚡)
- ✅ اتجاه RTL ودعم كامل للعربية (خط Cairo مضمّن محليًا)
- ✅ قفل بكلمة مرور (SHA-256 محلي)

## 🗂️ بنية المشروع

```
├── app/  components/  lib/  public/   ← كود الموقع (Next.js 16)
├── android/                          ← مشروع أندرويد (Capacitor) الجاهز للبناء
├── capacitor.config.ts               ← إعدادات التطبيق (الاسم، المعرّف...)
├── build-apk.sh                      ← سكربت بناء APK محليًا
└── .github/workflows/build-apk.yml   ← بناء APK تلقائيًا في GitHub Actions
```

## ⚡ طريقتان للحصول على ملف APK

### الطريقة 1: من GitHub Actions (الأسهل — بناء تلقائي في السحابة)

الملف الجاهز `build-apk.yml` موجود في مجلد `.github/workflows/` داخل هذا المستودع (ملف غير مضغوط بانتظار الإضافة). لإضافته مرة واحدة فقط:

1. من صفحة المستودع على GitHub افتح `.github/workflows/build-apk.yml`
2. اضغط **Edit** ثم **Commit changes** (أو انسخ محتواه يدويًا عبر **Add file → Create new file** بنفس المسار)
3. بعدها كل push يبني التطبيق تلقائيًا، وحمّل الـ APK من تبويب **Actions → Build Android APK → Artifacts** (اسم الملف: `daily-accounting-apk` ← `app-debug.apk`)
4. يمكنك أيضًا تشغيله يدويًا من زر **Run workflow**

### الطريقة 2: البناء محليًا

المتطلبات: Node.js 20+، Java 17، Android SDK (أو Android Studio).

```bash
./build-apk.sh
```

أو يدويًا:

```bash
npm ci
npm run build          # تصدير الموقع كملفات ثابتة إلى out/
npx cap sync android   # نسخ الملفات إلى مشروع أندرويد
cd android
./gradlew assembleDebug
```

النتيجة: `android/app/build/outputs/apk/debug/app-debug.apk`

## 📲 التثبيت على الهاتف

1. انقل ملف `app-debug.apk` إلى هاتفك (واتساب، كابل، تنزيل مباشر...)
2. افتح الملف على الهاتف
3. فعّل **"السماح بتثبيت التطبيقات من مصادر غير معروفة"** عندما يطلب النظام ذلك
4. التطبيق جاهز — بياناتك تبقى محفوظة حتى بعد إغلاقه (نفس قاعدة بيانات الموقع)

> 💡 النسخ الاحتياطي: من الإعدادات داخل التطبيق يمكنك تصدير نسخة احتياطية (JSON) أو تقرير PDF — في نسخة أندرويد تُفتح نافذة المشاركة لحفظ الملف أو إرساله.

## 🌐 تثبيته كتطبيق ويب (PWA) بدون APK — خيار فوري

إذا أعدت نشر هذا المستودع على Vercel (أو أي استضافة HTTPS)، يمكنك تثبيت الموقع كتطبيق على هاتفك مباشرة من المتصفح — بملء الشاشة وبدون إنترنت:

1. افتح الموقع في **Chrome** على هاتف أندرويد
2. اضغط ⋮ (القائمة) ← **إضافة إلى الشاشة الرئيسية (Add to Home screen)**
3. ستظهر أيقونة التطبيق ⚡ على شاشتك، وتفتح بملء الشاشة وتعمل بدون إنترنت

الموقع الآن مزوّد بـ `manifest.webmanifest` + أيقونات 192/512 + خدمة `sw.js` للتخزين المؤقت.

## 🔐 إصدار موقّع للنشر (اختياري)

نسخة Debug تكفي للاستخدام الشخصي. للنشر على متجر أو مشاركة أوسع، أنشئ keystore ووقّع نسخة Release:

```bash
cd android
./gradlew assembleRelease
```

ثم وقّع الملف بـ `apksigner` باستخدام keystore خاص بك، أو أضف إعدادات التوقيع في `android/app/build.gradle`.

## 🛠️ ملاحظات تقنية

- **الموقع الأصلي** يخزن البيانات في IndexedDB عبر Dexie — يعمل كما هو داخل WebView أندرويد بدون تعديل
- **الخطوط**: استُبدل `next/font/google` بخط Cairo المضمّن محليًا (`@fontsource/cairo`) حتى لا يحتاج التطبيق اتصالًا بالإنترنت
- **التصدير**: أُضيفت `lib/native.ts` لتوجيه تنزيل الملفات إلى نظام المشاركة في أندرويد عبر `@capacitor/filesystem` و `@capacitor/share`
- **معرف التطبيق**: `com.electrician.dailyaccounting` — يمكن تغييره من `capacitor.config.ts` (غيّره قبل أول نشر إذا كان سيُرفع لمتجر)
- عند تعديل كود الويب: `npm run build && npx cap sync android`
